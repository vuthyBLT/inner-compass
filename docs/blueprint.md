# **App Name**: EnneaSim

## Core Features:

- User Authentication: Secure user login/logout using Firebase Authentication with email.
- Quick Check Questionnaire: A brief questionnaire that provides a quick personality assessment based on Enneagram types.
- Deep Dive Questionnaire: An extensive questionnaire providing a detailed personality report with Enneagram scores and rankings.
- Interaction Simulation Tool: Simulate interactions between different Enneagram types, providing insights on communication styles and potential conflicts. The LLM uses reasoning to pick helpful prompts to start the simulation and guide it if necessary.
- Group Scenario Simulation: Simulate group scenarios and dynamics based on Enneagram types of the participants.
- Personalized Feedback: Generate tailored feedback and recommendations based on the user's Enneagram type and simulation outcomes. The LLM decides when and how to bring in facts or explanations.
- Payment Integration: Integrate PayPal Web Payments SDK for enabling premium features or donations.

## Style Guidelines:

- Primary color: Deep vibrant gray (#4A4A4A) for a modern, sophisticated feel.
- Background color: Light gray (#E0E0E0) to provide a neutral backdrop, offering contrast with the primary color.
- Accent color: Muted blue-gray (#778899) to highlight interactive elements and CTAs, complementing the primary color scheme.
- Body and headline font: 'Inter', a grotesque sans-serif, for a neutral and modern look, appropriate for both headlines and body text.
- Sticky bottom navigation menu styled like Android apps for easy access to main sections.
- Use simple, consistent icons that are easy to understand. Make use of the material design icon set to unify the user experience across the different modules.
- Subtle animations and transitions to enhance user experience and provide feedback on interactions.
